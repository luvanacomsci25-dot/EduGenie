# EduGenie: Google Gemini Powered Learning Assistant

## Pre-requisites
- Python 3.10+
- Google AI Studio API Key (Gemini API)
- Git installed

## Installation Steps
1. Clone repository: git clone https://github.com/luvanacomsci25-dot/EduGenie
2. Install Python 3.10+ from python.org
3. Get Gemini API Key from aistudio.google.com
4. Install dependency: pip install google-generativeai
5. Verify installation: python --version
